    How the value is worked out

    Implied value = TVL × category multiple × growth × age × breadth. The multiple is not a guess: for each category it is the median market-cap / TVL of the protocols in that category whose token already trades in this same snapshot; categories with fewer than three live comparables use the global median. Growth is the protocol's own 7-day TVL change, clamped to −50%…+100% and weighted 0.6. Age rewards a longer record with no token yet (0.70 + 0.30 × age up to 3 years; unknown age counts as 365 days). Breadth adds 5% per extra chain, up to four. Nothing is hardcoded by name: the same formula scores every row.
