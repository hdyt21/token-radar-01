A token launch radar that ranks pre-token protocols by an implied value built from live comparables: each category's median market-cap / TVL among protocols whose token already trades, times TVL, 7-day growth, age and chain breadth — plus a concrete farm plan for every protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
